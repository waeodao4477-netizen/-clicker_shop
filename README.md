# -clicker_shop
แฟร้งคลิกคลิก
เว็บไซต์ขายคีย์แคปคลิกเกอร์และพวงกุญแจสำหรับคีย์บอร์ด ที่มีเสียงคลิกสังเคราะห์และตัวการ์ตูนน่ารัก ระบบสั่งซื้อ ชำระเงินด้วย PromptPay จัดการสต็อก และรายงานยอดขายสำหรับแอดมิน พัฒนาด้วย Python (http.server + SQLite) ในไฟล์เดียว
โปรเจกต์ในรายวิชา ED251007 Computer Programming for Teachers คณะศึกษาศาสตร์ มหาวิทยาลัยขอนแก่น
ผู้จัดทำ: นายกิตติภพ หาญณรงค์ 683050133-5
ความสามารถ
สมัครสมาชิกและเข้าสู่ระบบ แยกฝั่งลูกค้ากับแอดมิน (เก็บรหัสผ่านแบบ hash PBKDF2-SHA256 พร้อม salt) พร้อมระบบลืมรหัสผ่านด้วยรหัสรีเซ็ต
โปรไฟล์ผู้ใช้และแอดมิน: เปลี่ยนรูปโปรไฟล์ (ครอปในเบราว์เซอร์) ตั้งชื่อเล่น เปลี่ยนรหัสผ่าน
หน้าร้าน: ดูสินค้าตามหมวด พิมพ์เลือกจำนวนได้ มีแจ้งเตือนเมื่อถึงลิมิตสต็อก และฟังเสียงคลิกของแต่ละคีย์แคป (18 เสียง)
ตะกร้าสินค้า: เพิ่ม ลด แก้จำนวน ลบ พร้อมคำนวณราคารวมและ VAT 7%
สั่งซื้อและตัดสต็อกแบบ atomic ป้องกันของขายเกินจำนวน
ชำระเงินผ่าน PromptPay QR พร้อมอัปโหลดสลิป และใบเสร็จรับเงิน
ติดตามสถานะคำสั่งซื้อ: รอชำระ / ชำระแล้ว / ตรวจสอบแล้ว / ยกเลิก
จัดการสินค้าและสต็อก (แอดมิน): เพิ่ม แก้ไข ลบ ปรับจำนวน และเปลี่ยนรูป QR รับเงิน
รายงานยอดขาย: ดูตามบิล รายวัน รายเดือน รายปี และรายสินค้า ส่งออก CSV (เปิดใน Excel ได้) และสั่งพิมพ์
แดชบอร์ด: สรุปยอดขายรายวัน รายเดือน รายปี เลือกช่วงวันที่เองได้ (แสดงเป็น พ.ศ.)
เทคโนโลยีที่ใช้
ภาษา Python 3.14 (ใช้เฉพาะ standard library ไม่ต้องติดตั้งเพิ่ม)
เว็บเซิร์ฟเวอร์: http.server
ฐานข้อมูล: SQLite (clicker_shop.db) ผ่านโมดูล sqlite3
ส่วนติดต่อผู้ใช้: HTML, CSS, JavaScript (Web Audio API สำหรับเสียงคลิก)
เครื่องมือเขียนโค้ด: Visual Studio Code
